  - **No text goes out with a placeholder left in** (for example "Hi {first}").
- Checked on every wedding: no server errors; counts agree on every page; wedding and birthday counts never mix; nobody is seated twice; one wedding's data is never visible from another; guest links only open their own invitation.

**First run tonight:** about 40,000 checks per machine. 4 weddings out of 1,000 failed, from 2 real bugs (both below). There were no server errors.
