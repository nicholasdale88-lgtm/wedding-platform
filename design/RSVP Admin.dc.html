What it will cost

Mobile Message charges 1.6¢ + GST (1.76¢) per text if you buy your credits within 30 days of signing up. Credits never expire, so one top-up of about $20 covers the whole wedding. After that the standard rate is 4¢ + GST (4.4¢). New accounts also get 50 free texts for testing.

One-time setup, about 20 minutes

  1. 1Mobile MessageCreate a free account at mobilemessage.com.au. Buy credits within 30 days to lock in 1.6¢ per text. Claim your free dedicated number so guests can text back. Under Settings, API, create an API username and password.
  2. 2Google SheetCreate a new Google Sheet. Open Extensions, Apps Script, delete the sample code and paste in backend/Code.gs from this project.
  3. 3SettingsIn Apps Script, Project Settings: set the time zone to Sydney. Add script properties ADMIN_KEY (2027), MM_USER, MM_PASS, SENDER (your dedicated number, e.g. 61400000000), ADMIN_MOBILE (your mobile, for replies that need you) and INVITE_URL (your invitation link ending in ?g=).
  4. 4Switch onRun the setup function once and approve access to Sheets, Drive (for photos) and sending. This starts the 15-minute check that sends scheduled texts. Then Deploy, New deployment, Web app, Execute as me, Who has access: Anyone. Copy the URL.
  5. 5ConnectPaste the URL above and press Connect, then send it to Claude to build into the website. In Mobile Message, Settings, Webhooks, set inbound messages to the same URL with ?hook=2027 on the end so guest replies come straight here.
